# todo-list-ai

Список задач для ежедневной работы. Сделан на React и TypeScript. Работает полностью в браузере: без бэкенда, данные хранятся в `localStorage`.

## Возможности

- **Быстрое добавление.** Задача добавляется по Enter или кнопкой «Добавить». Пробелы по краям и повторные пробелы убираются. На пустой ввод форма показывает подсказку.
- **Подробности задачи.** Под полем ввода есть кнопка «Подробнее». Она открывает необязательные поля:
  - **Описание** — многострочное, до 1000 символов. В списке показывается под названием, не больше трёх строк.
  - **Приоритет** — низкий, средний или высокий, по умолчанию средний. В списке подписывается только высокий и низкий приоритет, чтобы не загромождать строки.
  - **Срок** — выбирается в стандартном поле даты, его можно изменить или убрать. Незавершённые задачи с прошедшим сроком помечаются «Просрочено».
- **Редактирование в списке.** Кнопка с карандашом или двойной клик по тексту. Доступны все поля: название, описание, приоритет и срок. Enter в поле названия или кнопка «Сохранить» сохраняют. Escape в любом поле или кнопка «Отмена» отменяют. Пустое название не сохраняется.
- **Отметка выполнения** одним нажатием. Если задача после отметки исчезает из текущего фильтра, появляется уведомление с кнопкой отмены.
- **Удаление с отменой.** После удаления задачи или очистки выполненных 5 секунд можно нажать «Отменить» или Ctrl+Z. Задачи возвращаются на свои прежние места.
- **Фильтры** «Все», «Активные», «Выполненные» со счётчиками. Если задача добавлена в режиме «Выполненные», список переключается на «Все», чтобы её было видно.
- **Сводка в шапке и счётчик внизу:** сколько задач активно и сколько осталось, с правильным склонением.
- **Сохранение в `localStorage`.** Повреждённые данные (невалидный JSON, не массив, некорректные записи) отбрасываются и не ломают приложение. Задачи, сохранённые до появления описания, приоритета и срока, загружаются со значениями по умолчанию. Некорректное значение в одном из этих полей тоже заменяется значением по умолчанию, а сама задача сохраняется.
- **Пустые состояния** с понятным текстом: свои для пустого списка и для каждого фильтра.
- **Работа с клавиатуры.** Видимый фокус. После удаления фокус переходит на соседнюю задачу, а не теряется. Уведомления озвучиваются скринридерами.
- **Мобильные устройства.** Все действия доступны без hover. Области нажатия — не меньше 40px.

## Стек

React 19, TypeScript (strict), Vite, обычный CSS. Иконки — `lucide-react` (три штуки: галочка, карандаш, корзина).

## Запуск

Нужен Node.js 20.19+.

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:5173.

| Команда             | Что делает                                   |
| ------------------- | -------------------------------------------- |
| `npm run dev`       | dev-сервер с горячей перезагрузкой           |
| `npm run typecheck` | проверка типов TypeScript                    |
| `npm run build`     | проверка типов и production-сборка в `dist/` |
| `npm run preview`   | локальный просмотр production-сборки         |

## Структура

```
src/
  App.tsx                 компоновка, фильтр, уведомления, управление фокусом
  hooks/useTodos.ts       состояние задач и операции: добавить, изменить, удалить, восстановить
  lib/todos.ts            чистые функции: нормализация и валидация полей, приоритеты, фильтрация, склонения
  lib/dueDate.ts          чистые функции для срока: проверка даты, «сегодня», просрочка, формат
  storage.ts              чтение и запись localStorage с валидацией и значениями по умолчанию
  types.ts                типы Todo, TodoDetails, Priority, Filter
  icons.ts                единые размер и толщина линий иконок
  index.css               стили и дизайн-токены
  components/
    TodoForm.tsx          поле добавления задачи и раскрывающиеся подробности
    TodoDetailsFields.tsx поля описания, приоритета и срока (общие для формы и редактора)
    FilterBar.tsx         переключатель фильтров
    TodoItem.tsx          строка задачи: отметка, редактирование всех полей, удаление
    TodoMeta.tsx          строка под названием: приоритет и срок
    EmptyState.tsx        тексты пустых состояний
    Toast.tsx             уведомление с действием «Отменить»
```

Бизнес-логика (`useTodos`, `lib/`, `storage.ts`) отделена от компонентов. Список задач хранится в одном месте. Отфильтрованный список и счётчики вычисляются при рендере и в отдельном state не дублируются. ID задач создаются через `crypto.randomUUID()`.

Срок хранится как календарный день в формате `YYYY-MM-DD` — ровно то, что возвращает `<input type="date">`. В метку времени он не превращается, поэтому часовой пояс не может сдвинуть дату. Просрочка определяется сравнением со «сегодня» по локальному календарю пользователя.
